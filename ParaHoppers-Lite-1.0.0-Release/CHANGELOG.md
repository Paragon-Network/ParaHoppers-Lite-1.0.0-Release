# ParaHoppers Lite 1.0.0 release notes

- Separate legacy and modern plugin artifacts for the 1.13 material boundary.
- Collector hoppers, XP upgrades, filters, links, persistence, and virtual diamond mining tool retained.
- Bedrock and storage block mining protections retained.
- Restored `/ph stats`, its help and tab entries, and the `parahoppers.admin.stats` permission.
- Removed compatibility build notes and development tests from the release source package.
- No licensing requirement or license check.

The user reported live passes for 1.7.10, 1.8.9, 1.12.2, 1.13.2, 1.16.5, 1.20.6, and 1.21.8 on Build 8. The final source changes and JARs require a build and final smoke test. Version 26.1+ is unverified.
